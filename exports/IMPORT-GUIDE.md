# YouCan landing page import guide

This file is based on the actual Import page JSON example supplied in the conversation. Import `youcan-landing-page.json` through YouCan's Import page feature, preview it, select the intended product in YouCan's own page settings, and verify the native Express checkout section before publishing.

The template is Arabic RTL and reusable as a design shell, but the JSON alone does not prove automatic live binding for every product field. Update bracketed content with accurate product details. Do not assume changing the selected product automatically updates all copy, images, price, variants, inventory, or SEO.

Use only YouCan's native checkout. Test product, variant, quantity, totals, shipping, inventory, order creation, validation, duplicate submissions, and confirmation in a real test order before advertising. This export has not been imported into a live store or tested with a live COD order.
