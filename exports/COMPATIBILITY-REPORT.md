# Compatibility report

The provided Import page sample establishes a top-level `sections` array and `settings` object. The Mimouzza source app is React/TypeScript with a Convex-backed COD form; that app-specific order mutation cannot be copied into a YouCan JSON file.

The export is a design template, not a verified dynamic product integration. You must test the import and native YouCan Express checkout in the target store. No live import or COD order has been tested.
